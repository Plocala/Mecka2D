# ⚠️ Projeto Arquivado: Mecka2D

> **Este repositório foi arquivado e não receberá mais atualizações.**
>
> Mecka2D foi um experimento pessoal e uma tentativa inicial de criar uma mini engine 2D sobre LÖVE2D. O projeto não atingiu um estado funcional, e a falta de documentação aliada a decisões organizacionais ruins tornaram sua manutenção inviável.

## 🗃️ Por que o repositório está arquivado?

- O código reflete um período de aprendizado inicial, com muitas más práticas, falta de clareza e uma estrutura confusa.
- Não há documentação ou registros que permitam recuperar o contexto do projeto.
- Tentar “consertar” Mecka2D demandaria um esforço equivalente a começar do zero – o que não faz sentido neste momento.
- Arquivar o repositório mantém o histórico da minha trajetória, ao mesmo tempo que mantém meu perfil do GitHub organizado e focado em projetos ativos e bem estruturados.

## 🎯 O que fica de aprendizado?

- A importância de documentar desde o primeiro commit.
- Manter uma organização mínima no código (separação de responsabilidades, convenções).
- Saber reconhecer quando um projeto não está mais valendo o esforço de resgate é uma habilidade profissional.
- Arquivar algo não significa apagar o passado – significa organizá-lo de forma transparente.
